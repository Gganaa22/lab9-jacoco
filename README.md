## D: Хамралт 100% боловч алдаа амьд

Зааг утгын тестүүд (`letterGradeBoundaries`) нэмэхэд 1 тест унав
(`results/mvn-test-D-fail.txt`):

```
ScholarshipCalculatorTest.letterGradeBoundaries:75 expected: <D> but was: <F>
```

Унасан тест нь `score 60 -> D` байсан. Шалтгаан нь `letterGrade`-д `score > 60` гэж бичигдсэн,
гэтэл спецификаци 60-ыг "D" гэж заасан. Засвар: `> 60` → `>= 60`
(commit `Fix letterGrade: > 60 -> >= 60, spec says 60 is D`). Эцсийн үр дүн:
30 тест ногоон, 100% хамралт (`results/mvn-verify-final.txt`, `results/jacoco-final.csv`).

**Дүгнэлт:** `score > 60` ба `score >= 60` хоёр нь ижил хоёр салаа (үнэн/худал) үүсгэдэг.
Тиймээс 65 ба 30 гэсэн тестүүд хоёуланд нь ижил замаар ордог тул branch хамралт 100% байхад
алдаа үл үзэгдэгч болсон. Зөвхөн яг зааг утга 60-ыг шалгасан тест л ялгааг илрүүлсэн.
Хамралт нь тест кодын аль мөр, салааг ажиллуулсныг хэмждэг. Харин ажилласан үр дүн
спецификацитай таарч байгаа эсэхийг хэмждэггүй. Иймд хамралт нь хэрэгтэй хэрэгсэл ч
хангалттай нотолгоо биш.
